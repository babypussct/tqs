# 血战长坂坡模式简介

此为三国杀OL-血战长坂坡模式的新月杀移植版，力求忠于原作。

## 玩法

- 模式由2人进行，游戏开始时先决定先后手
- 抓将阶段：双方各自随机3名暗置武将，同时从将池中随机选出6名明置武将，由暖方（后手）开始轮流选择3名明置武将
- 选将阶段：无视副将机制，强制启用副将，所以双方各从抓将阶段的六名武将里选择两张武将牌组成主副将
- 牌堆准备时，在标+军争牌堆基础上去掉4张牌（闪电、闪电、梅花2藤甲、方块Q无懈可击），共156张

### 特殊规则

- 转化牌触发技能时，一个回合只能触发一次
- 因技能触发体力上限变化时，体力上限不会小于2，同时不会大于5
- 武将牌背面朝上时，无法使用自身翻面技能使自身正面翻上

## 特殊牌改动

- 诸葛连弩
  锁定技，你使用【杀】的次数上限+3（来自统率三军）
- 兵粮寸断
  置于目标角色判定区里。若判定结果不为♣：摸牌阶段，其少摸一张牌；摸牌阶段结束时，除其外的角色各摸一张牌。（来自忠胆英杰的【草木皆兵】）
