# Candidate CP07: hosting độc lập Mac

Chuẩn bị cấu hình ngày 12/10/2026. **Chưa deploy hoặc xác minh Docker/Caddy/TLS/4G trên host thật.** Môi trường phiên này không có executable Docker/Caddy; chưa có DNS/SSH host được cấu hình. FreeKill hiện hành giữ nguyên.

1. Build/test candidate. Dùng runtime đã pin, không tự nâng packages. Chạy `node deploy/mobile/package-release.mjs /absolute/pinned/runtime /new/release`, rồi `node deploy/mobile/verify-release.mjs /new/release`. Manifest chứa SHA-256 từng file và MD5 flist; không đưa credentials/node_modules vào gói.
2. Chuyển release đã xác minh tới `/opt/tqs-mobile/releases/<candidate>`. Đặt domain, IP server game, RELEASE_DIR trong bản env theo `deploy/mobile/env.example`, ngoài source. Domain phải trỏ tới host có cổng 80/443; nếu đổi subnet, đổi cả IP proxy/gateway cùng subnet.
3. Trên host có Docker Compose: `docker compose --env-file /operations/mobile.env -f deploy/mobile/compose.yaml config`, `docker compose --env-file /operations/mobile.env -f deploy/mobile/compose.yaml up -d --build`. Caddy tự TLS, proxy WSS tới gateway; gateway chỉ mở trong mạng container, runtime/dist chỉ đọc. Caddy bỏ CF-Connecting-IP và ghi X-Forwarded-For; gateway chỉ tin IP proxy cố định.
4. Smoke `/gateway/healthz`, manifest/bundle hashes qua HTTPS; đăng nhập/trận bot và hai client; kiểm Origin từ domain khác bị từ chối. Ghi kết quả thật. Healthz chỉ xác nhận process HTTP, không khẳng định FreeKill hoặc bundle đang sẵn sàng. Theo dõi container health, restart count, bộ nhớ và số connection; log xoay vòng 3×10 MB. Gateway áp connection/queue/burst quotas; các ngưỡng này chưa có load benchmark production.
5. Restart/rollback chỉ sau khi mọi ván đã kết thúc. Gateway hiện không có live-drain API. Thay RELEASE_DIR sang release trước, xác minh lại hashes rồi chạy Compose up. Không rebuild/restart gateway khi có người đang chơi. Để thử rollback thật: chạy ván trước/sau, kiểm MD5/hashes/login và GameOver; ghi evidence. Chưa có bằng chứng rollback host thật trong phiên này.

Node-forge: npm audit hiện báo 1 high về RSA signature verification (`GHSA-86w9-cpqp-85rv`, chưa có fix trong registry ở lần kiểm). Code client dùng random bytes, PEM public key parse và RSA **encrypt**, không gọi signature verification. Không đánh dấu dependency sạch hoặc tự nhận advisory đã sửa. Trước release cần ghi chấp nhận rủi ro có căn cứ hoặc thay dependency bằng giải pháp tương thích đã kiểm login; không đổi thuật toán mà server yêu cầu.

Các gate còn PENDING: iOS/Android vật lý, 4G, TLS host thật, restart/reboot/rollback và quota benchmark. Docker image tags ở cấu hình là major tags; release production phải pin image digests sau khi build/xác minh trên host đích, chưa có digest được bịa trong tài liệu này.
