## Hợp đồng cần có trước khi chuyển đổi giao thức

1. Server giữ canonical physical IDs; codec biến đổi dữ liệu **trước khi CBOR được gửi tới từng physical socket** (owner, opponent, observer, reconnect độc lập). Lá kín cần opaque reference khó đoán, duy nhất theo mỗi audience, không tái sử dụng. Chỉ public/authorized card được truyền canonical ID.
2. Bảo đảm không tiết lộ thứ tự/quan hệ draw pile qua chuỗi `PrepareDrawPile`, `ShuffleDrawPile`, `SyncDrawPile`, `ChangeCardArea` và snapshot. Đánh lại handle sau shuffle hoặc khi chuyển khu vực/quyền xem; tùy tình huống gửi số lượng thay vì mảng ordered handles. Giữ counts và semantics cho client.
3. Bổ sung abstraction `localCardRef`/unknown-card trong Lua client/CardManager/KnownCardTracker, tách identity bản địa khỏi canonical server ID; đồng bộ owner hand, đối thủ, observer, public zones, marks và private `$` piles. Đánh giá riêng printed/virtual card IDs âm, chưa được bao phủ bởi mô hình positive-ID.
4. Mỗi request liên quan chọn/đánh/trả bài (`AskForCardChosen`, Poxi, UseCard, Response, discard...) phát allowlist **theo audience và request**; server dịch ngược token rồi kiểm tra lại quyền sở hữu, area, số lượng, thời điểm và luật. Cấm ID kín tự đoán, token từ audience khác, replay, token hết hạn, thiếu số lượng hoặc nhiều hơn yêu cầu. `reveal` thu hồi handle; khi `rehide` tạo handle mới. Client không thể quên kiến thức đã thấy nhưng không được dùng handle cũ để theo dõi lá kín.
5. Observer không kế thừa bản chiếu của seat đang xem. Reconnect tạo session audience mới và bỏ token/request cũ. Không ghi token hoặc card IDs bí mật vào log/record/evidence. Chỉ bật protocol mới khi server + client thông báo được cùng version; các mode khác giữ nhánh cũ.
